# AI-Manager-Baro

바로매니저(AI 중간관리자) — GS25 매장 태블릿 앱 전시용 프로토타입 (iPad 오프라인 웹 앱)

앱 주소: https://hyeon-director.github.io/AI-Manager-Baro/

## iPad 설치 방법
1. 전시용 iPad의 Safari에서 위 앱 주소를 엽니다. (인터넷 연결 필요, 최초 1회)
2. 공유 버튼 → '홈 화면에 추가' → 이름 '바로매니저' 확인 → 추가
3. 홈 화면의 바로매니저 아이콘으로 한 번 실행해 첫 화면이 뜨면 설치 완료 (영상·이미지·글꼴 등 모든 파일이 iPad에 저장됨)
4. 오프라인 확인: 비행기 모드를 켜고 아이콘으로 다시 실행 → 정상 동작 확인

## 전시 운영 팁
- 관람객이 앱을 빠져나가지 못하게 하려면 iPad '사용법 유도(Guided Access)'를 켭니다.
  설정 → 손쉬운 사용 → 사용법 유도 → 켬, 앱 실행 후 측면(또는 홈) 버튼 3번 누르기 → 시작
- 가로 방향 기준. 12.9/13형 iPad는 원본 크기(1366×1024), 그 외 iPad는 비율에 맞춰 자동 축소됩니다.
- 앱을 완전히 종료(위로 쓸어 올리기) 후 다시 실행하면 입력값·진행 상태가 처음으로 돌아갑니다.
  (단, AI 버튼 안내 말풍선은 기기에서 처음 한 번만 표시됩니다)
- 앱 내용을 수정해 다시 올린 경우, iPad에서 앱을 인터넷 연결 상태로 한 번 실행했다가 종료 후 재실행하면 새 버전으로 바뀝니다.
